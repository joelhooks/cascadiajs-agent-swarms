# Zara Zhang: How to Build Something Small

Sources:
- X: https://x.com/zarazhangrui/status/2050445806428438734
- Essay: https://zarazhang.substack.com/p/how-to-build-something-small

Captured for CascadiaJS talk reference.

## Core claim

AI changes the economics of software enough that small, opinionated software becomes worth building again.

Old world:

```text
software expensive → justify broad TAM → committee-safe product → generic tool
```

AI world:

```text
software cheap → build niche thing → express opinion → find weird 10k people
```

## Useful excerpts / claims

- Most products fail not because they were too narrow, but because they targeted too wide.
- If you are everything to everybody, you become nothing to nobody.
- Software is a form of self-expression.
- AI makes generic software easier to produce, so opinion/character matters more.
- A small product can resonate because its philosophy resonates.
- You can build what would get rejected in a big-tech product review meeting.
- Build first, understand later.
- Adults should start with real-world problems and work backwards into learning.
- LLMs are good at adding things, bad at subtracting; the human job is to cut.
- “Build something small and elegant. Software is a medium for storytelling.”

## Concept contribution

Zara gives a product/learning reason for “small cartridges”:

```text
Small software is no longer a compromise.
It is the natural unit for opinionated, playable, AI-native work.
```

This helps avoid the trap where “agent swarm” sounds like enterprise orchestration only. The talk can argue that the best way to learn the medium is to build small weird cartridges that expose coordination patterns.

## Talk-safe phrasing

- `Cheap software makes small software viable again.`
- `When everyone can generate generic software, taste becomes infrastructure.`
- `A cartridge is small enough to play, but opinionated enough to teach.`
- `The human role is not only to prompt. It is to subtract.`
- `Build first, understand later is play in engineering clothes.`

## Where it fits

Use this after the “play is how we learn affordances” thesis.

Sequence:

```text
1. New medium arrives.
2. We do not yet know its durable patterns.
3. Build small weird things to discover affordances.
4. Package the ones that work as cartridges.
5. Use cartridges to teach, coordinate, and scale judgment.
```

## Caveat

Zara's essay is about solo/side-project making more than team-scale agent swarms. Do not overclaim it as evidence for distributed coordination. Use it as evidence for small/opinionated/playful artifact-building in the AI era.
